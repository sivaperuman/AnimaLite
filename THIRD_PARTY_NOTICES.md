Roles used below:

* **linked** — imported into the AnimaLite process at run time;
* **development only** — used to build, lint, type-check or test; not imported by

* **redistributed** — a copy is present in this repository.

Nothing in this repository is currently **redistributed** or **modified**: no

### FFmpeg licensing note

FFmpeg's terms are set by the build that is installed, not by AnimaLite. The
build used for the checks in `docs/verified-commands.md` reports these
license-relevant configuration flags:

```
--enable-gpl --enable-libx265 --enable-libx264
```

`--enable-gpl` means **that build is distributed under the GPL**, not the LGPL.
`animalite doctor` records the full `configuration:` string of whichever build is
actually present and warns when a GPL-configured build is detected, so the
licensing position of a given deployment is inspectable rather than assumed.

AnimaLite invokes FFmpeg as a subprocess and does not ship it. A subprocess
boundary is a relevant fact, not a universal compatibility exemption: bundling,
linking or distributing an FFmpeg build together with AnimaLite requires separate
legal review, and so does distributing output produced with a `--enable-nonfree`
build. See `docs/licensing.md`.

## Not yet present

No model code, model weights, checkpoints, reference artwork or upstream
inference runtime is present in this repository. Package A integrates no learned
model.

When Package B adds one — a pinned RIFE/ncnn CPU candidate is the named first
candidate (requirements section 9.1) — each of the following must be recorded
here **separately**, because they are frequently governed by different terms:

* the upstream **source code** licence;
* the **weights / checkpoint** licence, including any territorial or
  field-of-use restriction. A model repository's top-level badge is not
  sufficient evidence;
* any **third-party components** the runtime links (codecs, BLAS kernels, ncnn
  itself);
* whether AnimaLite links, invokes, modifies or redistributes each artifact;
* the CR-024 / section 14.2 mapping to rights disposition, `use_eligible` and
  `eligibility_block_kind`.

`animalite.contracts.profile.EngineProfile` already carries `weights`, `binaries`
and `license_evaluation` fields for this, and validation rejects execution of a
profile that declares an artifact with no verified content hash
(`VAL-PROFILE-ARTIFACT-UNVERIFIED`).

Do not add AnimaLite copyright headers to third-party files, and do not claim
ownership of an unmodified upstream checkpoint or source file.
